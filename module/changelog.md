# 更新日志

## v1.4.9.11

> 对比基准：线上版本 **v1.4.8.4**。只写你能看到、能用到的变化。

### 一、新增「高级设置」——本版重点

**这是什么**

一个**默认隐藏**的调试面板。以前遇到"字体没生效""某个 App 闪退""图标变方框"，只能在主界面翻报告；现在集中到一个带分区的面板里，每一项都写了它是干嘛的、怎么看结果。

**怎么进去**

```
1. 打开 WebUI，停在主界面
2. 滑到最下面，找到「当前版本」那一行（显示 v1.4.9.11 的位置）
3. 连点 7 次（连续点，中途别停）
4. 弹出输入框 → 输入口令：cfs2026
5. 进入「高级（调试用）」
```

进去以后：

```
· 标题右边「锁定」：点它确认后，主界面入口重新隐藏
  想再进：连点版本号 7 次 + 口令
· 右上角「✕」关闭；进入子页后变成「‹ ✕」
· 子页不显示「锁定」，避免误触
```

**分区只读保护**：面板会先读你的系统。不是你系统的分区显示为只读，卡片上写「本机不是 X 系统」，点了没反应 —— 在小米手机上不会误开三星的开关。

### 二、界面外观：可换背景 + 毛玻璃

```
· 新增「设置背景图片」：选一张图当背景，原图导入、最大 24MB，不压缩
· 所有浮层（选字体、字属性、诊断报告、各种菜单）改成毛玻璃
· 三档背景预设：预设一偏暗 / 预设二最亮最清 / 预设三最糊
  点一下自动把滑块调到对应值，显示「当前：预设一/二/三」；手动拖过就显示「自定义」
· 三个滑块：背景暗化、背景模糊、卡片不透明度，拖动即时生效
· 有壁纸时按钮不再用强调色（改回卡片色），避免抢眼
· 平板 / 横屏：模糊层按屏幕尺寸铺满，四周不再露一条清晰的边
· 没设壁纸时：预设与滑块不可用（避免以为没生效）
```

### 三、状态显示更准

```
· 「槽位总数 / 实际挂载 / 逐个核对」三项都能取到真实数字（不再显示 "-"）
· 切换字体后：卡片「当前」立即更新，
  「当前实际生效」保持旧值、「待生效（下次重启后）」显示新选择
· 顶部数字在切换、拨开关后跟着刷新，不用手动刷新页面
```

### 四、卸载 / 重装更干净

```
· 卸载：物理删除背景图、清掉界面外观，重装后壁纸不再"复活"
· 重装：安装号变化时自动清掉上一套界面设置，回到默认外观
· 字体库仍按原规则：还有另一个字体模块装着时保留共享字体库
```

### 五、模块更新（UI 更新）

```
· 检查更新、下载、安装、重启提示这一整套实测通过
· 版本比对按 versionCode 数字比较，不会出现"新版提示已是最新"
```

### 六、这一版没有改的东西

```
· 默认行为：默认仍然「不替换任何系统字体」，装完要先选
· 开关默认值：一个都没改
· 机型识别与槽位扫描规则：除上面写到的，其它与 1.4.8.4 一致
```

### 升级提示

```
1. 从 1.4.8.4 直接覆盖安装即可，装完重启一次
2. 第一次打开 WebUI，字体列表和状态数字需要几秒加载，属正常
3. 想换背景：高级设置 → 界面自定义 → 设置背景图片
```
