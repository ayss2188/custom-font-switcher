# 更新日志

## v1.4.9.5

### 修复：重启后仍提示「已安装完成，重启后生效」（这次从源头清）

**原因**：界面读的是 `$LIB/.update/state` 这份状态文件。
更新装上后这份文件里留着 `done` / `pending`，界面每次打开都会读到，
于是红色「立即重启生效」一直在。前几版只在浏览器里清，清不掉它。

**已修**：开机早期（`post-fs-data` 与 `service` 两处）检查一次 ——
本机 `versionCode` 已经大于等于状态里记录的目标版本，就直接删掉这份过期状态。
界面读不到状态，自然不会再提示重启。

> 之前版本的内容不变。
