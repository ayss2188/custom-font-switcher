# 自定义字体切换模块

**导入自己的字体，一键切换全局系统字体**

适用于 **Magisk · KernelSU · APatch**（含 SukiSU 等 KernelSU 分支）

[下载最新版](https://github.com/ayss2188/custom-font-switcher/releases/latest) · [更新日志](CHANGELOG.md) · [问题反馈](https://github.com/ayss2188/custom-font-switcher/issues)

## 一、详细介绍

### 1. 核心理念：你的字体，你做主

本模块**不内置任何字体**，刷入后默认「无字体」，不改动系统任何东西。你可以在 WebUI 里导入自己喜欢的 TTF / OTF 字体（可多选），点一下就能切换，重启生效。

- **字体库**：所有导入的字体集中存放在 `/data/adb/custom_font_lib`，更新模块不会丢失；卸载模块时会一并删除，不留残留；
- **随时切换**：点选字体卡片即可切换，选「无字体」立即恢复系统默认；
- **可变字体友好**：导入可变字体（Variable Font）时，系统调节字体粗细会在 wght 轴上平滑过渡；静态字体则各字重外观相同；
- **自动体检**：导入时自动读取字体的字符覆盖范围，判断是「中英文」「仅英文/数字」还是「仅中文」，并据此决定替换哪些字体槽，避免英文字体把中文换成方块。

### 2. 深度适配：按本机真实字体槽替换

不同系统的字体槽数量差异很大：HyperOS 有几十个，ColorOS 更是上百个，OriginOS / Flyme / 原生也各不相同。本模块**不使用固定清单硬铺**，而是：

1. **只替换手机上真实存在的字体文件**，不凭空创建不存在的路径；
2. 候选槽位来自三方面：系统字体配置 XML 中的主文字族、各系统验证过的已知文件名、厂商命名规则扫描；
3. 按文件名给每个槽位分角色，**默认不碰**日韩及其他文字、符号 / Emoji、衬线 / 等宽 / 时钟 / 斜体等高风险槽位（可在设置里关闭保留）；
4. 自动发现未知厂商分区（`/xxx/fonts`），不依赖机型白名单。

**零重复占用**：所有槽位都用硬链接指向字体库里的同一个文件，无论替换多少个槽位，实际只占一份字体的空间。

支持的系统：

- 小米系：澎湃OS / HyperOS / MIUI（小米 / 红米 / POCO）
- OPPO 系：ColorOS（OPPO / 一加 / realme）
- vivo 系：OriginOS（vivo / iQOO）
- 魅族：Flyme
- 三星 One UI、荣耀 MagicOS、华为 EMUI / 鸿蒙（AOSP 兼容版）、Nothing OS（通用适配）
- 原生 / 类原生 / 谷歌 Pixel / GSI：兜底通用适配

刷入后 `module.prop` 描述会直接显示「识别到的系统」和「当前生效的字体」，一眼确认适配结果。

### 3. 模块自带挂载：不再需要元模块

以往的字体模块在 KernelSU / APatch 上必须先装元模块（如 Hybrid Mount）才能挂载字体。本模块**自己完成挂载**：

- **Magisk**：在 post-fs-data 阶段挂载；
- **KernelSU / APatch**：在 post-mount 阶段挂载（在其他模块之后，不容易被覆盖）；
- 能覆盖 `my_product`、`mi_ext` 等厂商分区里的字体槽，这些分区很多元模块并不支持；
- WebUI 状态栏会显示「实际挂载：成功 N 个」，诊断报告里还有「实际生效检测」，挂没挂上一目了然。

如果你的管理器比较特殊、自带挂载不工作，可以在设置里改回「交给管理器挂载」（传统方式）。

### 4. 安全设计

- **先生成、再校验、最后提交**：切换字体时新文件全部就绪才替换旧的，中途失败（如存储空间不足）会保留原来的字体；
- **开机保护**：选了字体后如果没能正常开机，下次开机会自动恢复为「无字体」，并在 WebUI 提示；
- **不改系统分区**：所有修改都是 systemless 的，禁用或卸载模块即可完全恢复；
- **不改字体配置 XML**：只替换字体文件本身；
- **冲突检测**：发现同时启用了其他字体模块，会在安装界面、WebUI 和模块描述里提醒。

### 5. 谷歌字体兼容

Chrome、Gmail 等 Google 应用有时会通过 GMS 的 FontsProvider 下载官方 Google Sans，导致英文数字又变回默认。本模块内置「谷歌字体兼容」开关（WebUI 内操作）：

- **原理**：仅停用 GMS 的 FontsProvider 组件（可逆、不卸载、不清数据、不动账户）；
- **效果**：Chrome、Gmail 等 Google 应用的英文数字回退到系统字体（即你选的字体），开启后立即生效，无需重启；
- **可逆**：随时一键「关闭兼容」；**卸载模块时会自动恢复**，且只恢复本模块自己停用过的组件。

### 6. GitHub 在线更新

- WebUI 里可以**检查更新、查看更新日志、一键下载并安装**，不用再去网盘找新版；
- 下载后自动校验 sha256 和模块 ID，校验不通过不会安装；
- Magisk / KernelSU / APatch 管理器的模块列表也会显示「有更新」；
- 更新后**自动恢复你上次选的字体**，字体库和设置全部保留。

### 💡 已知局限

- **谷歌商店（Play Store）**：新版把 Google Sans 直接打包进了 APK，属于「应用内置字体」，任何系统级字体模块都无法替换——Chrome / Gmail 生效、商店不变属正常现象；
- **QQ、微信等个别页面**：走独立的渲染逻辑或自带字体，不会随系统改变；
- **游戏、阅读器、网页 CSS 字体、图片文字**：不经过系统字体，不受影响；
- **魅族个性化字体**：Flyme 另有 `/data/customizecenter/font` 字体机制，本模块只覆盖系统字体链路；
- **TTC 合集**：不能直接导入，请先在电脑上用 `tools/optimize_font.py --face 0` 取出单个字体。

## 二、刷前准备与避坑指南（必看！）

- **Root 权限环境**：支持 Magisk（v20.4+）/ KernelSU / APatch。
- **不需要元模块**：模块自带挂载，KernelSU / APatch 用户无需先装 Hybrid Mount 等元模块。
- **KernelSU / APatch 用户建议关闭「默认卸载模块」**：打开管理器设置，找到【默认卸载模块】并关闭，避免部分应用被隔离后看到的是系统默认字体。
- **停用其他字体模块**：多个字体模块会互相覆盖，刷入前请先停用。
- **Magisk 用户**：Magisk 没有 WebUI 入口，需要安装 [KsuWebUI](https://github.com/5ec1cff/KsuWebUIStandalone)（或 WebUI X）来打开管理界面。

## 三、关键设置：解决「部分生效 / 没完全变」问题

### 小米 / 澎湃系统

如果重启后发现「有的地方变了、有的地方没变」（例如设置界面变了但桌面没变）：

- **原因**：系统当前使用的字体还是默认的 MiSans 时，部分系统资源会被原厂主题字体覆盖；
- **解决方法**：
  1. 打开手机 **设置 ➔ 系统个性化 ➔ 字体**；
  2. 将系统字体手动切换为【小米兰亭Pro】；
  3. 切换后系统会全量重新加载字体，即可全局生效。

> 此步骤仅小米 / 澎湃系统需要。ColorOS、OriginOS、Flyme、原生系统一般刷入重启即可。

### 其他排查

1. 打开 WebUI，看状态栏「实际挂载」是否显示成功；
2. 点「查看诊断报告」，看「实际生效检测」是否接近已替换的槽位数；
3. 如果提示「本次开机没有执行自带挂载」，在设置里改为「交给管理器挂载」后重新选字体、重启；
4. 仍然不行，把诊断报告「保存到 Download」后附在 Issue 里反馈。

## 四、详细刷入与使用教程

### 1. KernelSU / APatch

1. 打开管理器，进入【模块】页面，点击「从存储安装」，选中下载好的 `custom-font-switcher.zip`；
2. 刷入完成后重启手机；
3. 重启后进入【模块】列表，找到「自定义字体切换模块」，点击 **WebUI** 按钮打开管理界面；
4. 导入字体 ➔ 点选字体 ➔ 点「立即重启生效」。

### 2. Magisk

1. 打开 Magisk，进入【模块】页面，点击「从本地安装」，选择 `custom-font-switcher.zip`；
2. 刷入完成后重启手机；
3. 安装 KsuWebUI（包名 `io.github.a13e300.ksuwebui`）；
4. 回到 Magisk【模块】列表，点模块卡片上的 **「操作」** 按钮即可调起管理界面；
5. 导入字体 ➔ 点选字体 ➔ 点「立即重启生效」。

### 2. 导入字体

- **推荐**：点「选择字体文件（可多选）」，在内置文件浏览器里勾选一个或多个 `.ttf` / `.otf`，一次导入，直接复制，速度很快；
- **备用**：「改用系统选择器」，经 WebView 分块传输，大字体会比较慢；
- 导入后可以点卡片上的 ✎ 修改名称和替换范围（自动 / 中英文 / 仅英文数字 / 仅中文）。

## 五、WebUI 状态与生效说明

由于系统机制限制，切换字体后不会自动重启，页面上提供了状态提示：

- **当前实际生效**：此时此刻系统正在使用的字体；
- **待生效（下次重启后）**：你刚点选、已生成好的新字体；
- **已替换槽位 / 实际挂载**：本次替换了多少个字体槽、开机时成功挂载了多少个。

生效方法：选好字体后，点击页面底部的「立即重启生效」，或自行手动重启手机。

**高级设置**：

- 保留日韩及其他文字的字体槽（推荐开启）；
- 保留衬线 / 等宽 / 时钟 / 展示 / 斜体槽（推荐开启）；
- 模块自带挂载（推荐开启）。

修改设置后会按当前选择自动重新生成，重启生效。WebUI 支持深浅色跟随系统、主题切换与过渡动画。

## 六、字体精简工具（电脑端，可选）

体积很大的字体（几十 MB）会占用更多内存、首次加载更慢。刷机包 `tools/optimize_font.py` 可以在电脑上精简字体：

```sh
pip install fonttools
python optimize_font.py 原字体.ttf -o 精简后.ttf --family "My Sans"
python optimize_font.py 原字体.ttf -o out.ttf --wght 400        # 可变字体转静态
python optimize_font.py 合集.ttc -o out.ttf --face 0            # 从 TTC 合集取出单个字体
```

默认保留拉丁 / 标点 / 假名 + GB2312 简体 + Big5 常用繁体（约 1.2 万字），冷门字会回退到系统字体。
