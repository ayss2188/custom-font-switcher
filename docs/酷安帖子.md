========================================

【自定义字体切换模块 v1.0】你的字体，你做主

不再内置固定字体，而是把「换字体」这件事交还给你：导入自己喜欢的 TTF / OTF 字体，点一下就能全局替换，重启生效。HyperOS、ColorOS、OriginOS、Flyme、原生等多系统自动适配，KSU / APatch 不再需要元模块，还支持在 WebUI 里一键在线更新。

（图1：WebUI 主界面）

一、详细介绍

1. 核心理念：默认不替换，想换什么换什么

刷入后默认是「无字体」状态，不改动系统任何东西。打开 WebUI 导入你自己的字体（可多选），点一下字体卡片就能切换，选「无字体」即恢复系统默认。

- 字体库集中存放在 /data/adb/custom_font_lib，更新、重装模块都不会丢；
- 导入时自动「体检」：读取字体实际包含哪些字符，自动判断是「中英文」「仅英文/数字」还是「仅中文」，英文字体不会把中文换成方块；
- 可变字体友好：导入 Variable Font 可变字体，系统调节字体粗细时可平滑过渡；
- 内置文件浏览器，多选导入、直接复制，几十 MB 的字体也是秒导。

2. 中英文分别选择

很多机友喜欢「中文用 A 字体、英文数字用 B 字体」，现在 WebUI 里直接分别指定即可：

- 中文字体：替换中文槽位和中英混合的系统主字体；
- 英文 / 数字字体：替换 Roboto、Google Sans 等拉丁字体槽位。

两个选同一个字体就等于普通切换。

（图2：中英文分别选择）

3. 深度适配：按本机「真实字体槽」替换，不多不少

- 为什么不用固定清单？不同系统的字体槽数量差异很大：HyperOS 有几十个，ColorOS 更是上百个，OriginOS / Flyme / 原生也各不相同，同一系统不同版本还会变。固定清单要么漏槽（字体混搭、部分没变），要么乱铺（凭空多出一堆挂载）。
- 本模块的做法：切换时实时读取手机上的字体目录和系统字体配置（fonts.xml），结合各系统验证过的字体槽清单和厂商命名规则，只替换手机上真实存在的字体文件。
- 默认保护高风险槽位：日韩及其他文字、Emoji / 符号、衬线、等宽、时钟、斜体等槽位默认不动（可在设置里关闭保留），避免锁屏时钟、终端、表情乱掉。
- 零重复占用：所有字体槽都直接指向字体库里的同一个文件，替换一百个槽位也只占一份字体的空间。

支持的系统：

- 小米系：澎湃OS / HyperOS / MIUI（小米 / 红米 / POCO）
- OPPO 系：ColorOS（OPPO / 一加 / realme）
- vivo 系：OriginOS（vivo / iQOO）
- 魅族：Flyme
- 三星 One UI、荣耀 MagicOS、华为 EMUI / 鸿蒙（AOSP 兼容版）、Nothing OS：通用适配
- 原生 / 类原生 / 谷歌 Pixel / GSI：兜底通用适配

刷入后模块描述会直接显示「识别到的系统」和「当前生效的字体」，一眼确认适配结果。

4. 模块自带挂载：KSU / APatch 不再需要元模块

以往的字体模块在 KernelSU / APatch 上必须先装 Hybrid Mount 等元模块、重启一次，字体才能挂载。本模块自己完成挂载：

- Magisk：开机 post-fs-data 阶段挂载；
- KernelSU / APatch：开机 post-mount 阶段挂载（排在其他模块之后，不容易被覆盖）；
- 能覆盖 my_product、mi_ext 等厂商分区里的字体槽（很多元模块并不支持这些分区）；
- WebUI 会显示「实际挂载：成功 N 个」，诊断报告里还有「实际生效检测」，挂没挂上一目了然。

个别特殊环境下自带挂载不工作，也可以在设置里一键切回「交给管理器挂载」（传统方式）。

5. 安全设计：可以失败，但不能把系统搞坏

- 先生成、再校验、最后提交：新字体全部准备就绪才替换旧的，中途失败（比如存储空间不足）会保留原来的字体，不会出现一半新一半旧；
- 开机保护：选了字体后万一没能正常开机，下次开机自动恢复为「无字体」，并在 WebUI 提示；
- 不改系统分区、不改字体配置文件，禁用或卸载模块即完全恢复；
- 冲突检测：发现你同时开着别的字体模块，安装界面、WebUI 和模块描述都会提醒。

6. 谷歌字体兼容

Chrome、Gmail 等 Google 应用有时会通过 GMS 的 FontsProvider 下载官方 Google Sans，导致英文数字又变回默认。WebUI 内置「谷歌字体兼容」开关：

- 原理：仅停用 GMS 的 FontsProvider 组件（可逆、不卸载、不清数据、不动账户）；
- 效果：Chrome、Gmail 等应用的英文数字回退到系统字体（即你选的字体），开启后立即生效，无需重启；
- 可逆：随时一键「关闭兼容」；卸载模块时会自动恢复，而且只恢复本模块自己停用过的组件，不会误改你原来的设置。

（图3：谷歌字体兼容）

7. GitHub 在线更新

- WebUI 里可以「检查更新 / 查看更新日志 / 下载并安装」，不用再到处找新版；
- 下载后自动校验文件完整性和模块身份，校验不通过不会安装；
- 国内网络连不上 GitHub 时，可以在 WebUI 里设置下载镜像；
- Magisk / KernelSU / APatch 模块列表也会提示「有更新」；
- 更新后自动恢复你上次选的字体，字体库和设置全部保留，不用重新导入。

（图4：模块更新）

💡 已知局限

- 谷歌商店（Play Store）：新版把 Google Sans 直接打包进了 APK，属于「应用内置字体」，任何系统级字体模块都无法替换——Chrome / Gmail 生效、商店不变属正常现象；
- QQ、微信等个别页面走独立渲染或自带字体，不会随系统改变；
- 游戏、阅读器、网页指定的字体、图片里的文字，不经过系统字体，不受影响；
- 魅族另有个性化字体机制（/data/customizecenter/font），本模块只覆盖系统字体链路；
- TTC 合集字体不能直接导入，可用刷机包 tools 文件夹里的 optimize_font.py 在电脑上拆出单个字体。

二、版本说明

只有一个通用包，不区分版本：

- Magisk / KernelSU / APatch（含 SukiSU 等 KSU 分支）通用；
- 无内置字体，体积只有几十 KB；
- 功能全部包含：字体导入与切换、中英文分别选择、多系统自动适配、谷歌字体兼容、在线更新。

三、刷前准备与避坑指南（必看！）

- Root 环境：支持 Magisk（v20.4+）/ KernelSU / APatch。
- 不需要元模块：模块自带挂载，KSU / APatch 用户无需先装 Hybrid Mount 等元模块。
- KSU / APatch 用户建议关闭「默认卸载模块」：打开管理器设置，找到【默认卸载模块】并关闭，避免部分应用被隔离后看到的是系统默认字体。（图5）
- 停用其他字体模块：多个字体模块会互相覆盖，刷入前请先停用（包括旧版字体模块）。
- Magisk 用户：Magisk 没有 WebUI 入口，需要先安装 KsuWebUI（包名 io.github.a13e300.ksuwebui）或 WebUI X 来打开管理界面。

四、关键设置：解决「部分生效 / 没完全变」问题

1. 小米 / 澎湃用户（刷完必做）

如果重启后发现「有的地方变了、有的地方没变」（例如设置界面变了但桌面没变）：

- 原因：系统当前使用的主题字体还是默认的 MiSans 时，部分系统资源会被原厂字体覆盖；
- 解决方法：
  1. 打开手机 设置 ➔ 系统个性化 ➔ 字体；
  2. 将系统字体手动切换为【小米兰亭Pro】；
  3. 切换后系统会全量重新加载字体，即可全局生效。
- 参考（图6）

> ColorOS、OriginOS、Flyme、原生系统一般无需此步，刷入重启即可。

2. 所有系统通用排查

- 打开 WebUI，看「实际挂载」是否显示成功；
- 点「查看诊断报告」，看「实际生效检测」是否接近已替换的槽位数；
- 提示「本次开机没有执行自带挂载」时，在「替换范围（高级）」里关闭「模块自带挂载」，重新选一次字体后重启；
- 还是不行，把诊断报告「保存到 Download」，评论区或 GitHub 反馈时附上。

五、详细刷入与使用教程

1. KernelSU / APatch 刷入步骤

- Step 1：打开管理器，进入【模块】页面，点「从存储安装」，选中下载好的 custom-font-switcher.zip；
- Step 2：刷入完成后点「重启」；
- Step 3：重启后进入【模块】列表，找到「自定义字体切换模块」，点 WebUI 按钮打开管理界面；
- Step 4：导入字体 ➔ 点选字体（或中英文分别选择）➔ 点「立即重启生效」。

2. Magisk 刷入步骤

- Step 1：打开 Magisk，进入【模块】页面，点「从本地安装」，选择 custom-font-switcher.zip；
- Step 2：刷入完成后点「重启」；
- Step 3：安装 KsuWebUI；
- Step 4：回到 Magisk【模块】列表，点模块卡片上的「操作」按钮，即可调起管理界面；
- Step 5：导入字体 ➔ 点选字体（或中英文分别选择）➔ 点「立即重启生效」。
- 参考（图7）

3. 导入字体

- 推荐：点「选择字体文件（可多选）」，在内置文件浏览器里勾选一个或多个 .ttf / .otf，直接复制入库，速度很快；
- 备用：「改用系统选择器」，大字体会比较慢；
- 导入后点字体卡片上的 ✎，可以改名字和替换范围（自动 / 中英文 / 仅英文数字 / 仅中文）。

4. 从「自定义字体切换」旧版升级

- 直接刷入 v1.0 覆盖即可（虽然版本号看起来变小了，但内部版本码更大，管理器会正常按升级处理），字体库会保留，上次选的字体会自动恢复；
- 以后的新版本可以直接在 WebUI「模块更新」里一键安装。

六、WebUI 状态与生效说明

由于系统机制限制，切换字体后不会立即改变，需要重启。页面上有状态提示：

- 当前实际生效：此时此刻系统正在使用的字体；
- 待生效（下次重启后）：你刚点选、已经生成好的新字体；
- 已替换槽位 / 实际挂载：本次替换了多少个字体槽、开机时成功挂载了多少个。（图8）

生效方法：选好字体后，点击页面底部「立即重启生效」，或自行手动重启。

高级设置（一般保持默认即可）：

- 保留日韩及其他文字的字体槽（推荐开启）；
- 保留衬线 / 等宽 / 时钟 / 展示 / 斜体槽（推荐开启）；
- 模块自带挂载（推荐开启）。

修改设置后会按当前选择自动重新生成，重启生效。WebUI 支持深浅色跟随系统、主题切换与过渡动画。

## 评论区常见问题（可置顶）

- 刷了没变化？→ 先看 WebUI「实际挂载」，小米用户切一次小米兰亭Pro，还不行发诊断报告。
- 能不能内置字体？→ 为了避免版权问题，模块不带字体，请自行导入。
- 字体从哪找？→ 各大字体官网、开源字体项目（如思源、霞鹜文楷、MiSans、HarmonyOS Sans 等，注意各自的授权条款）。
- 检查更新失败？→ 国内网络连 GitHub 不稳定，在 WebUI「下载镜像」里填 https://ghfast.top 等加速地址。
- 卡开机了？→ 再重启一次会自动恢复「无字体」；仍不行就进安全模式或在管理器里禁用模块。
